## Kothalipi 0.1.3

- **No CPU spike after a model download.** The download is now checked while it arrives, instead of reading the whole 800 MB file again afterwards, which kept a CPU core at 100% for several seconds at the end of onboarding.
- **Voice models list fits the window.** On a smaller screen the list with "Other models" open ran under the Back and Continue buttons. It now scrolls inside its card.
- **Private by default.** The app's data folder and everything in it (your API keys and recordings) is now readable only by you.
