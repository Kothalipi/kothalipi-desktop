## Kothalipi 0.1.1

- **Menu bar only on Mac.** Kothalipi no longer shows in the Dock or the app switcher. It lives in the menu bar. Turn on Settings, Advanced, Show in Dock if you want the Dock icon.
- **A calmer overlay.** The recording pill has a smoother, voice-shaped wave, and the transcribing state is a breathing wave instead of a spinner.
- **Clear cloud errors.** When Gemini or OpenAI fails, Kothalipi now says why (key rejected, quota used up, no connection) instead of a bare "Transcription failed". Google's "API key not valid" reply is recognised as a bad key.
- **Less memory.** In Cloud mode the offline model is no longer loaded for every recording, and an idle offline model is freed after 2 minutes.
- **Gemini now works.** Gemini's transcription model sends its text in a field the app wasn't reading, so every cloud attempt looked empty and failed. Fixed.
- **Limits, explained.** When Gemini or OpenAI says a limit was reached, Kothalipi shows exactly which one (daily, per minute, or no credit), the number when the provider gives it, and how long to wait. Settings, Listening shows today's requests and minutes per engine, with links to the providers' own usage pages. Providers don't let apps read a key's remaining quota, so the counts are Kothalipi's own.
